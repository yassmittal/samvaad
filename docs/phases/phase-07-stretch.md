# Phase 7 — Stretch (only if ahead)

Not a sprint: a menu. Pick one only when Phases 0 to 6 are done, or when a day is clearly
spare. Each needs its own decision in `decisions.md` before it's built. Most valuable first.

| Option | Why | Rough size |
|--------|-----|------------|
| **Translation on Muse Spark Open** through Baseten (`meta-models/muse-spark-open-1026`), switchable per room | The "Best Build on Meta Open Weight Models" bonus ($10K). Needs Baseten credits. Compare latency and quality with the comparison script | S |
| **A better voice** (an open TTS model such as Kokoro on Modal, or a paid voice API) | The browser voice is the weakest part of the demo. Streaming audio back changes the protocol | M |
| **Speak while translating**: speak the translation sentence by sentence as deltas arrive, instead of after it's complete | Cuts perceived latency on long utterances | S |
| **Point the camera**: photograph a menu, sign or price tag; Muse Spark reads and translates it into the room | Uses Muse Spark's vision; a natural moment in a buyer/seller story | S |
| **Three or more people** in a room | The API already supports it; this is UI | S |
